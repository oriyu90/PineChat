基于本地大模型运行的自主思考型 AI 代理。

Pine Chat 是一款可连接 LM Studio 等本地模型运行的 macOS AI 代理应用。只需提供一份设计文档(.md)，"放手模式"就能自动开发应用，直至构建前的最后一步。

开源协议 GPL-3.0-or-later · 开发者：折田悠希(Yuki_Orita)

功能

调研、开发与联动，一个代理全部搞定。

不仅是聊天窗口：编程、调研与外部联动都交给同一个本地 AI 代理处理。

𓂀

自动连接本地 AI

自动连接 LM Studio(端口 1234)等兼容 OpenAI 接口的服务。建议使用 20B 级别及以上的模型。

𓅱

SearXNG 网络搜索

通过 SearXNG 实现注重隐私的网络搜索，并可在 Mac 上以后台服务自动启动。

𓃭

应用设计与自动开发

提供设计文档(.md)后，"放手模式"会自动完成开发，直到构建前的最后一步。

𓅔

Markdown RAG

将 .md 文件作为知识库(RAG)加载，让代理参考项目专属的资料。

𓀀

代理联动

连接 Discord、Telegram 与日历，自动汇总消息并代为对话。

◆

以 GPL-3.0-or-later 协议发布，源码在 GitHub 上可自由查看与修改。

使用方法

三步即可开始

  1. 启动本地 LLM 服务器

    在 LM Studio 中加载模型并启动服务器(默认端口 1234)。

  2. 安装 Pine Chat

    从 GitHub Releases 下载最新的 .dmg 文件并打开即可。

  3. 直接开始对话

    启动时会自动连接本地 AI。创建项目后即可开始开发、调研或闲聊。

系统要求

  • ◆ macOS 14.0 及以上
  • ◆ 本地 LLM 服务器(如 LM Studio)
  • ◆ 建议使用 20B 级别及以上模型
  • ◆ 从源码运行需要 Node.js / npm

从源码运行

执行 npm install 后运行 npm start，或运行 ./build.sh 构建 .dmg。
