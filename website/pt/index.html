Um agente de IA autônomo, rodando no seu LLM local.

Pine Chat é um app de agente de IA para macOS que se conecta a um modelo local como o LM Studio. Basta fornecer um documento de design (.md) e o modo "hands-off" constrói o app para você, até a etapa final.

Recursos

Pesquise, construa e fique conectado — tudo em um agente.

Mais que uma janela de chat: programação, pesquisa e integrações externas rodam por um único agente de IA local.

𓂀

Conecta-se à sua IA local

Conecta automaticamente ao LM Studio (porta 1234) ou a qualquer API compatível com OpenAI. Recomendado um modelo de classe 20B ou maior.

𓅱

Busca na web via SearXNG

Busca na web com foco em privacidade através do SearXNG, que também pode rodar como serviço em segundo plano no macOS.

𓃭

Design de app e build autônomo

Forneça um documento de design (.md) e o modo "hands-off" implementa o app até a etapa final do build.

𓅔

RAG em Markdown

Carregue arquivos .md como um dicionário de referência (RAG) para o agente usar conhecimento específico do projeto.

𓀀

Integrações de agente

Conecta-se ao Discord, Telegram e ao seu calendário para resumir atividades e manter conversas por você.

Como usar

Comece em 3 passos

  1. Inicie um servidor LLM local

    Carregue um modelo e inicie um servidor no LM Studio (porta padrão 1234).

  2. Instale o Pine Chat

    Baixe o .dmg mais recente na página de Releases do GitHub e abra-o.

  3. Comece a conversar

    Ele se conecta à sua IA local automaticamente ao abrir. Crie um projeto e comece a construir, pesquisar ou apenas conversar.

Requisitos

  • ◆ macOS 14.0 ou superior
  • ◆ Um servidor LLM local (ex.: LM Studio)
  • ◆ Recomendado: modelo de classe 20B ou maior
  • ◆ Node.js / npm para rodar a partir do código-fonte

Rodando a partir do código-fonte

npm install e depois npm start, ou execute ./build.sh para gerar um .dmg.
